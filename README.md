# Расчет раскладки изделий на печатном листе

Статический калькулятор для раскладки прямоугольных и круглых изделий на
печатном листе. Учитывает размеры изделия и листа, вылеты, поля, интервалы и
допускает поворот изделий.

## Ссылки

- Публичная страница: `https://sunpole.github.io/260003-print-sheet-layout-calculator/`
- Исходный код: `https://github.com/sunpole/260003-print-sheet-layout-calculator`

## Запуск

Откройте `index.html` в современном браузере. Зависимости не устанавливаются;
иконки загружаются из публичной CDN Font Awesome.

## Версия

Текущая версия — `0.1.0`. История изменений ведётся в `CHANGELOG.md`.

## Состав
